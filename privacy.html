适用范围

本说明适用于 Sidenote 浏览器扩展。Sidenote 是独立开发的 DeepSeek 网页辅助扩展，不代表 DeepSeek。

处理的数据与用途

扩展读取 DeepSeek 当前页面已加载的聊天文字，用于定位选中文字、显示追问及恢复显示关系。扩展在本机观察官网已有消息请求/响应中的会话编号、消息编号、关系与状态；对于通过扩展发送并匹配确认的追问，还会临时处理回答正文以实时显示。不读取登录 Cookie、认证请求头或令牌，不自行调用模型接口。

本地保存

浏览器扩展本地存储保存设置、完整选文和定位上下文、提问文字、草稿、会话与消息编号、显示归属；按需保存发送前主输入框的恢复信息。回答正文的额外本地副本默认关闭。开启后，仅保存追问所属问答的显示副本。关闭只停止新增和更新副本，不删除已有副本；选文、问题、草稿仍然保存。当前没有单独清除正文副本的菜单。

这些本地数据没有扩展提供的额外加密，不通过本扩展跨设备同步。刷新会丢失未持久保存的临时正文；官网已加载内容可用于重新恢复。

发送与第三方

点击发送时，完整选文、用户问题和已开启的简短回答指令会由官网输入框发给 DeepSeek。原始聊天记录由 DeepSeek 按其政策处理。扩展不向开发者服务器上传数据，没有分析遥测、广告跟踪、出售数据或云同步。用户主动打开回答中的外部链接时，相应网站按其自身政策处理访问。

保留与控制

本地保存的数据用于后续恢复，扩展没有定期自动过期清理。关闭窗口不会删除官网消息。可以通过浏览器管理或卸载扩展清除其本地存储；这不删除 DeepSeek 官网聊天记录，官网记录应在官网管理。关闭本地副本开关不能替代清除已有数据。

支持与变更

隐私问题请联系以上开发者邮箱。政策变更时更新此页面及生效日期。

本网站

本站使用 GitHub Pages 托管，不设登录、表单、分析脚本或广告。托管服务可能处理访问网站所需的技术信息，其处理方式请参阅 GitHub 隐私声明。这与扩展在本机处理聊天内容是不同的过程。
